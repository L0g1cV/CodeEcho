# CodeEcho

> **Whisper code. Echo clarity.**

CodeEcho is a niche note-taking app designed for bilingual developers preparing for technical interviews. It leverages AI to transform your fragmented algorithm thoughts into polished, professional English explanations.

## ✨ Features

- **Yuque-inspired Dashboard** – Hierarchical organization of algorithm notebooks
- **Unified Markdown Workbench** – Distraction-free canvas for problem-code-reflection fusion
- **Smart Import (Omni-Paste)** – Client-side HTML-to-Markdown sanitization
- **The Echo Core** – AI sidebar that comprehends intent and teaches professional phrasing
- **Zen Review Mode** – Toggleable sidebars for focused study sessions

## 🛠️ Tech Stack

| Layer          | Technology                                             |
| -------------- | ------------------------------------------------------ |
| Frontend       | Vue 3 + TypeScript + Vite + Pinia                      |
| Backend        | Go + Gin                                               |
| Database       | PostgreSQL                                             |
| Object Storage | Cloudflare R2 / Aliyun OSS                             |
| AI             | BYOK (Bring Your Own Key) – OpenAI / Claude / DeepSeek |
